Token Radar radar-2: 190 pre-token protocols ranked by implied value from a sealed DefiLlama snapshot (2026-11-14, 758 protocols, 40 on the watchlist). Implied value is a log-scale model of TVL, 7-day growth, age with no token, and chain breadth — no protocol name is special-cased. Every row carries a concrete 7-step farm plan with costs and times, and the static dashboard is sortable, filterable (category, chain, min TVL, watchlist-only, search), with a detail view for every protocol and a live-token view set aside.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
